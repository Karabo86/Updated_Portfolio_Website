Power BI · Power Query · Excel

Website UAT Dashboard

At the WRC I manage and review UAT, and going through several Excel result files to find failed tests is slow. To make that repeatable, I built this report on a sample website UAT dataset: 72 test cases across seven modules and 12 defects, tracked from failed test through defect, fix and retest.

My role
Designed the test case structure, cleaned and modelled the data in Power Query, and built the Power BI report.
Process
  1. Logged test cases and defects per module in Excel as testing happened
  2. Used Power Query to clean and standardise the data into a master workbook
  3. Modelled it in Power BI with filters by module and priority level
  4. Added an open defects view (severity, status, target fix date) to support retest meetings
Result
On the sample data: 72 test cases, 69% pass rate and 9 open defects, with Critical and High items visible on the first screen. The same structure is the template for real UAT cycles.
Tools
  • Excel
  • Power Query
  • Power BI

SQL

Data Cleaning & Standardisation, Global Layoffs Dataset

A raw dataset of global layoffs, full of duplicates, blank fields and inconsistent formatting, cleaned into an analysis-ready table using SQL alone.

My role
Wrote every query: staging, deduplication, cleaning and the final table structure.
Process
  1. Created a staging table so the raw data was never touched directly
  2. Removed duplicate rows using ROW_NUMBER() over CTEs
  3. Standardised inconsistent industry names, country names and date formats
  4. Handled NULLs and blanks, then used CREATE TABLE, INSERT, UPDATE, DELETE and ALTER TABLE to finish the table
Result
A clean, de-duplicated dataset ready for analysis, with the full query history public on GitHub.

  • SQL
  • MySQL
